About

libavoid-rust is a Rust port of the libavoid C++ library, originally created by Michael Wybrow at Monash University. It provides efficient connector routing algorithms for diagram editors, supporting both polyline (any-angle) and orthogonal (horizontal/vertical) routing modes.

🔗 Original C++ Library 📚 Adaptagrams Project
